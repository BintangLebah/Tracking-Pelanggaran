Referensi Implementasi

Section "Lainnya":
Class .lainnya-hide digunakan sebagai pengganti Tailwind hidden karena Tailwind's hidden menggunakan !important yang tidak bisa di-override oleh selector CSS apapun.
Checkbox #lainnya-check ditempatkan di luar .page-wrapper sebagai sibling. Saat dicentang (simulasi "Lainnya" dipilih), selector #lainnya-check:checked ~ .page-wrapper .lainnya-hide { display: block; } menampilkan section.
Dalam produksi, JavaScript akan mendeteksi perubahan value pada select dan menambah/menghapus class pada section ini.

Preview Foto:
Sama seperti form Tambah Siswa — checkbox #has-foto mengontrol visibilitas. Saat file dipilih, JS menambahkan checked pada checkbox dan mengganti isi preview div dengan gambar asli.
Tombol ✕ menghapus preview dan mengembalikan ke state upload.

Optgroup Select:
Emoji pada label optgroup (🟢🟡🔴) akan tampil di sebagian besar browser. Styling optgroup sangat terbatas di CSS — warna teks dan font-weight mungkin tidak konsisten di semua browser.
